**Date:** 2026-07-10  
**Issue:** Inject nahi ho raha, bubble show nahi, Zygisk Next pe "Stop by zygote crashed"

## Kya fix kiya

1. **Phone / telephony allow** — SMS block hooks ab `com.android.phone` me chalenge
2. **Zygote-safe load** — config file I/O `preAppSpecialize` se hata ke `postAppSpecialize` me
3. **Whitelist only** — sirf UPI + SMS + phone processes pe module load
4. **JNI pthread fix** — overlay aur root-hide workers ab sahi thread attach karte hain

## Tumhe kya karna hai

1. Purana module disable mat chhodo — **nayi zip flash** karo: `hivirtus-zygisk-hook-v2.71.0.zip`
2. **Reboot** (2 baar agar APatch ho)
3. Zygisk Next kholo — **zygote crashed** hatna chahiye, zygote64 green/active
4. PhonePe / Paytm / koi UPI app kholo → **gold V bubble** left side
5. Bubble tap → Intercept ON + mock number save
